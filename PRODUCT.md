# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Prospective clients evaluating the studio and deciding whether to start a project.

## Product Purpose

The site helps prospective clients assess the studio's work and services, review client feedback, and start a project inquiry.

## Positioning

Open decision: the existing site presents the studio as an independent, principal-led design practice, but this positioning has not been confirmed by the user.

## Capabilities and Constraints

The site includes project portfolio, service descriptions, studio information, client reviews, a brand-fit check, and an inquiry flow. The requested page structure is Home (hero, selected work, brand audit, reviews, footer), with dedicated Services, Projects, and About pages. The header links to Home, Services, Projects, and About, alongside the existing Start a Project button.

## Brand Commitments

The existing site identifies the studio as Wong's Digital Arts and includes its logo and dark charcoal/purple visual identity. These are incumbent implementation details; no additional brand constraints were confirmed.

## Evidence on Hand

Portfolio content, review quotes, client names, impact metrics, and imagery are present in `src/data/studioData.ts` and `src/assets/`. Their factual authenticity has not been verified in this session; do not add or strengthen claims.
